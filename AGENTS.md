# VideoMotion package
Use `.claude/skills/videomotion/SKILL.md` (or the `.agents` equivalent) and the adjacent `tiktok-an-toan` skill for video creation. Commands in those skills run from `luma-video/`.
Only the VideoMotion workflow is included. Historical footage and project dates in the original skill are references, not bundled inputs or current product facts. Start from `examples/` and capture fresh sources.
Back up existing files before modifying them. Ask before deleting anything. Never commit secrets, browser sessions, generated videos, or the downloaded Mixkit sound files.
The runtime currently targets Windows with Microsoft Edge and FFmpeg on PATH. `.venv/` is at this repository's root. Never synthesize speech without the user's requested video task; the Vibi call consumes their API credits.
